# منصة أخبار النصر + إدارة مهام تحريرية

موقع أخبار رياضية عربي (RTL) بواجهة Jinja2 + HTMX، مع نظام مهام تحريرية مدمج،
وتكاملين أساسيين مع الذكاء الاصطناعي، ولوحة إدارة يتحكّم بها المدير تحكّماً كاملاً
بالتصنيفات (إضافة/تحرير/حذف) دون التأثير على الأخبار.

التصميم والنية موثّقان بالكامل في [`PROJECT_MAP.md`](PROJECT_MAP.md) — وهو المرجع الوحيد للبنية.

---

## 1. المتطلبات

| الأداة | الإصدار |
|---|---|
| Python | **3.13** (الحد الأدنى 3.11 لأن SQLAlchemy 2.1.3 يفرضه) |
| pip / uv | الأحدث |

لا حاجة لأي شيء آخر: لا Node، ولا Docker، ولا قاعدة بيانات خارجية.

## 2. التشغيل من مجلد نظيف

```powershell
# 1) إنشاء البيئة وتثبيت التبعيات
uv venv --python 3.13 .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 2) إعداد مفتاح الجلسات (إلزامي قبل أي نشر حقيقي)
Copy-Item .env.example .env
# ثم افتح .env واضبط SECRET_KEY على نص عشوائي طويل
# مثال توليد مفتاح عشوائي طويل: .venv\Scripts\python.exe -c "import secrets;print(secrets.token_urlsafe(48))"

# 3) إنشاء الجداول ثم تعبئة بيانات تجريبية
.\.venv\Scripts\python.exe -m flask --app run init-db
.\.venv\Scripts\python.exe -m flask --app run seed

# 4) التشغيل
.\.venv\Scripts\python.exe run.py
```

ثم افتح <http://127.0.0.1:8000> — ولوحة التحرير على <http://127.0.0.1:8000/auth/login>.

### حسابات التجربة (تُنشأ بـ `flask seed` فقط)

| المستخدم | كلمة المرور | الدور |
|---|---|---|
| `admin` | `admin123` | مدير |
| `editor` | `editor123` | محرّر |

## 4. الإعداد (`env`)

كل القيم تُقرأ من `.env` ثم `.env.local` (يتجاوز الأول). كل مفتاح له افتراضي
يعمل بدون ضبط — انظر `.env.example` للقائمة الكاملة.

| المتغيّر | الافتراضي | ملاحظة |
|---|---|---|
| `SECRET_KEY` | قيمة تطوير غير آمنة | **يجب** تغييره قبل النشر |
| `OPENAI_API_KEY` | *(فارغ)* | **اختياري** — غيابه يعطّل ميزتَي AI فقط |
| `AI_MODEL` | `gpt-6-luna` | Responses API |
| `ITEMS_PER_PAGE` | `13` | حجم صفحة الموقع العام |
| `LEAGUE_ENABLED` | `1` | قسم دوري روشن؛ `0` يُخفيه كلياً |
| `LEAGUE_TTL` / `LEAGUE_TIMEOUT` | `600` / `5` | ثوانٍ بين تحديثَي الكاش ومهلة نداء ESPN |
| `LOG_DIR` / `LOG_FILE` | `logs/app.log` | تدوير 2MB × 5 |
| `HOST` / `PORT` | `127.0.0.1` / `8000` | خادم `waitress` |

## 5. ميزتا الذكاء الاصطناعي

| الميزة | المسار | متى تعمل |
|---|---|---|
| AI-1 · تلخيص خبر بالعربية | `POST /editor/articles/<id>/ai-summary` | محرّر/مدير + `OPENAI_API_KEY` |
| AI-2 · اقتراح مهام من نص | `POST /tasks/suggest` | أي موظف + `OPENAI_API_KEY` |

**بدون مفتاح** يعمل الموقع كاملاً، وتعيد المسارتان `503` برسالة عربية تشرح
السبب. لا يوجد `500` أبداً، ولا يتعطّل أي مسار آخر.

## 6. قسم دوري روشن السعودي

ساحة أسفل الهيدر مباشرة يحوط بها **الخبر الرئيسي** (السلايدر): «مباريات هذا
الأسبوع» يمينه و«آخر النتائج» يساره، ثم «أحدث الأخبار» بعرضها الكامل كما
كانت. لكل مباراة: الشعاران والاسم عربياً، الملعب والمدينة بالعربية، توقيت
الرياض، والتاريخ الميلادي **والهجري** (تقويم أم القرى).

- المصدر: واجهة ESPN العامة `site.api.espn.com` لدوري `ksa.1` — **بلا مفتاح API**.
- **ملخص المباريات المنتهية**: عند المرور بالماوس على نتيجة منتهية يظهر تلميح
  بالأهداف (المسجّل + الدقيقة)، البطاقات (أصفر/أحمر بالأسماء)، التبديلات
  (داخل/خارج + الدقيقة)، وقائمة صنّاع الأهداف. أسماء اللاعبين تُعرض بالعربية
  عبر قاموس مرفق `app/league/players_ar.json` + ترجمة تلقائية للجديد تُخزَّن
  في `players_ar.json` بمجلد الكاش (تفشل بهدوء وتُبقي الاسم الإنجليزي عند تعذّر الشبكة).
- **معاينة المباريات القادمة**: عند المرور بالماوس على «مباريات هذا الأسبوع»
  يظهر تلميح ذكي من ملخص ESPN للمباراة + جدول الترتيب: ترتيب الفريقين ونقاطهما
  في روشن، سلسلة آخر ٥ مباريات (ف/ت/خ)، آخر المواجهات المباشرة، الهداف وصانع
  الأهداف في كل فريق، الغيابات (موقوف = طُرِد في آخر مباراة) والإنذارات،
  واحتمالات الفوز محسوبة من أسعار المراهنة. تُحسب البطاقات من مباريات النافذة
  المنتهية وتُخزَّن في `instance/cards.json` ولا تُعاد إلا عند تغيّر قائمة المباريات.
- التحديث تلقائي كل `LEAGUE_TTL` ثانية (الافتراضي 10 دقائق) مع كاش في
  `instance/league.json`، والشعارات تُنزَّل مرّة واحدة إلى `app/static/img/teams/`.
- عند تعذّر الشبكة تُستخدم النسخة المخزَّنة، وعند غيابها يُخفى القسم — لا تعطّل
  للرئيسية أبداً.
- تحديث يدوي (مفيد لجدولة زمنية):
  `.\.venv\Scripts\python.exe -m flask --app run fetch-league`
- بلا شبكة في الاختبارات: `TestConfig.LEAGUE_ENABLED = False`.

## 7. بنية المشروع

```
app/
  __init__.py        create_app() + الفلاتر العربية + معالجات 403/404/500 + CLI
  config.py          Config / DevConfig / TestConfig
  extensions.py      db, login_manager, csrf
  models.py          النماذج الخمسة + slugify() + التسميات العربية
  seed.py            بيانات تجريبية
  forms/base.py      ترجمة أخطاء WTForms إلى العربية
  core/              logging_setup.py (طابور غير حاجب) · pagination.py
  ai/service.py      summarize() + suggest_tasks() + سجل ai_usage
  league/service.py  دوري روشن: جلب ESPN + كاش + تواريخ ميلادية وهجرية
  auth/  admin/  editor/  news/  tasks/    _blueprints_ формы والمسارات
  templates/         base + قالب لكل route + 8 partials (منها league.html)
  static/css/app.css نظام تصميم واحد بمتغيّرات CSS
  static/img/nassr-logo.png شعار المنصة بصيغة PNG
  static/img/teams/  شعارات أندية دوري روشن (تُنزَّل تلقائياً)
tests/               conftest.py + 9 ملفات اختبار
run.py               نقطة الدخول: waitress على 127.0.0.1
```
